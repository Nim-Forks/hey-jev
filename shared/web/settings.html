Where to get the keys

Fish Audio (required — the voice): sign in at fish.audio, then create a key on the API keys page. The s2.1-pro-free model this app uses is free on the API until the end of November 2026.
TypeSafe / Jev: typesafe.ai — or skip it and use KEV or OpenRouter below.
OpenRouter (answers + fallback decisions): create a key at openrouter.ai/settings/keys.

Keys are stored in this browser's localStorage only, sent to the PC per connection, never saved on the PC. Paste them — never retype.

Timer push to this phone (ntfy)

Install the ntfy app and subscribe to a topic with an unguessable name (that name is the password), then paste the topic here — timer and reminder alerts land as phone notifications even when this page is closed. Leave empty to use the server's default topic.

While this page is open, alerts also vibrate, show a notification and speak right here — allow notifications when the browser asks (or tap HOLD TO TALK once).
