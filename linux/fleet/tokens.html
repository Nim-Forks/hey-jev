ACCESS TOKENS

deva — works on all 21 instances. Each subdomain stores it once in localStorage; enter it at the token prompt on first visit.
the shared primary token — also valid everywhere (the fleet shares one .env base + REMOTE_TOKENS=deva extra). Heading to a new instance? Either token connects; tokens do not transfer automatically.
Never paste backend credentials into an instance token prompt. Cloudflare (cfut_…), Liquid (liquid_…), System One (so_live_…), KEV/OpenRouter keys are server-side credentials for decision/voice backends — they belong in the instance's .env on the geekom or in ~/bin/.env.ai on K12, never in the browser. Entering them at the token prompt only fails auth.
Effective gate thresholds (per instance class): KEV-class deployments 0.45 · OpenRouter-only 0.65 · see inventory.
